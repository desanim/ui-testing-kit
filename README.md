# UI Testing Starter Kit
> Dành cho vị trí: UX Tester / UI Tester / Accessibility Tester (Usability + WCAG 2.2 AA)
> Đọc trong 5 phút: Case study flagship → Checklist → Templates

## Kit này chứa gì (chỉ 5 file quan trọng)
1. [`case-study/README.md`](case-study/README.md) — 1 case flagship: usability + a11y trên flow Checkout (R1→R2, có số)
2. [`checklists/usability-test-checklist.md`](checklists/usability-test-checklist.md) — checklist mang vào buổi test
3. [`checklists/accessibility-wcag-checklist.md`](checklists/accessibility-wcag-checklist.md) — checklist audit WCAG 2.2 AA (Axe + keyboard + screen reader)
4. [`templates/test-plan-1pager.md`](templates/test-plan-1pager.md) — test plan 1 trang copy-paste
5. [`templates/a11y-bug-report.md`](templates/a11y-bug-report.md) — bug report map WCAG, dev đọc là fix được

## Cách dùng khi apply job
- Gắn link repo này vào CV / LinkedIn, mục "Portfolio".
- Khi phỏng vấn: mở case-study, kể theo flow 3 phút: Goal → Method → Top finding có số → Fix → Re-test.
- Khi nhận bài test thực hành: copy test-plan + checklist ra dùng ngay.

## Skill chứng minh qua kit này
Usability (moderated, SEQ/SUS, success rate) · Accessibility (Axe, keyboard-only, NVDA/VoiceOver, WCAG 2.2 AA) · Reporting (Insight→Evidence→Recommendation, P0-P3)
