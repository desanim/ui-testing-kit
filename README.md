# UI Testing Starter Kit

> Read in 5 minutes: Flagship case study → Checklists → Templates

## What's inside (only 5 essentials)
1. [`case-study/README.md`](case-study/README.md) — 1 flagship case: usability + a11y on a Checkout flow (R1→R2, with numbers)
2. [`checklists/usability-test-checklist.md`](checklists/usability-test-checklist.md) — in-session usability checklist

## How to use when applying
- Link this repo on your CV / LinkedIn under "Portfolio".
- In interviews: open the case study, tell it in 3 minutes: Goal → Method → Top numbered finding → Fix → Re-test.
- For take-home tests: copy the test plan + checklists and use them directly.
