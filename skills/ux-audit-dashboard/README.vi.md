# UX Audit Dashboard Builder — Skill độc lập

Skill này hướng dẫn AI chuyển báo cáo UX, usability, accessibility hoặc QA thành dashboard có thể truy nguyên bằng chứng, theo dõi khắc phục và retest.

## Nội dung ZIP

- `SKILL.md`: hướng dẫn skill tương thích cấu trúc Agent Skills.
- `references/data-contract.md`: schema và quy tắc chuẩn hóa finding/evidence.
- `references/dashboard-design.md`: cấu trúc giao diện, khả năng tiếp cận và hành vi.
- `templates/findings.template.json`: mẫu dữ liệu trống để bắt đầu dự án mới.
- `templates/dashboard-review-checklist.vi.md`: checklist trước khi bàn giao.

ZIP không chứa dữ liệu hoặc ảnh audit GoSeedUp, credentials, SDK tracking, hay ứng dụng dashboard đã xuất bản. Hãy cung cấp báo cáo nguồn và yêu cầu AI tạo dashboard trong môi trường có khả năng tạo file.

## Cách dùng

1. Giải nén ZIP.
2. Đưa thư mục skill vào thư mục skills của công cụ AI bạn sử dụng hoặc tải lên theo quy trình hỗ trợ skills của công cụ đó.
3. Bắt đầu yêu cầu: “Dùng UX Audit Dashboard Builder để chuyển các file báo cáo này thành dashboard responsive; giữ nguyên provenance và đánh dấu rõ phần chưa kiểm.”

Skill là quy trình hướng dẫn AI, không phải ứng dụng dashboard chạy độc lập. Dashboard được tạo sẽ là artifact riêng.
